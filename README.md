# SYNAPSE AI

> Convierte conversaciones en trabajo terminado.

Portfolio landing-page case study by Sara Duque.

## Goal
Drive visitors to start a free trial or request a product demo.

## Stack
Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Motion for React.

## Codex-ready
This repository uses repository-scoped Codex skills under `.agents/skills/` and project guidance in `AGENTS.md`.

Included skills:
- `apple-interaction-audit`
- `conversion-landing`
- `responsive-accessibility`
- `seo-performance`
- `motion-polish`

## Run locally
```bash
npm install
npm run dev
```

Quality checks:
```bash
npm run lint
npm run typecheck
npm run build
```

## Branch model
`main` stable · `develop` integration · `feature/*` work branches.

## Status
Initial technical scaffold and design/conversion brief prepared. Final visual design and production content are intentionally pending.
